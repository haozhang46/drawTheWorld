# Author flow — Penpot import kit

Free cloud: [https://design.penpot.app](https://design.penpot.app) (sign up, no paid plan needed for this).

## Import

1. Create a project → new file (e.g. `Draw The World — Author`).
2. Set artboard size **390 × 844** (or use frames already in each SVG).
3. Drag each `.svg` onto the canvas (or File → import if available).
4. SVG text may become outlines in Penpot — treat these as **layout references**, retype labels if you need editable text.

## Screens (Author §2)

| File | Step |
|------|------|
| `01-capture-target.svg` | Find / capture 标的物 (Captured Target) |
| `02-gen-img-chat.svg` | gen img tab — chat → Canvas preview |
| `03-asset-ready.svg` | Save Asset or pick own image |

Flow rule **C**: Anchor and Asset can be prepared in either order; World Save needs both.
